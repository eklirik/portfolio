# Портфолио EKLIRIK

Одностраничный сайт на двух языках (RU/EN): 3D-персонажи, брендинг, игры Roblox.
Каждая работа открывается в окне с галереей, зумом (клик, колёсико, щипок) и описанием.

## Как открыть локально

```
py -3.12 -m http.server 8090 --directory portfolio
```
Затем открыть http://localhost:8090

## Файлы

- `index.html` — разметка страницы
- `assets/style.css` — оформление
- `assets/app.js` — логика: язык, карточки, окно просмотра
- `assets/content.js` — **все тексты RU/EN**, контакты, бренды, игры
- `assets/media.js` — список картинок и описания 3D-моделей (создаётся скриптом, руками не править)
- `media/` — сжатые картинки (WebP) и анимации (MP4)
- `tools/build_media.py` — собирает `media/` и `assets/media.js` из исходных папок
- `tools/make_og.py` — картинка-превью для ссылок в соцсетях

## Как добавить работу

1. В `tools/build_media.py` добавить картинки в словарь `IMAGES` (или модель в `MODELS`).
2. Запустить `py -3.12 tools\build_media.py` из папки `portfolio`.
3. В `assets/content.js` добавить тексты (название, тип, описание на двух языках).

Работу можно добавить в `content.js` заранее, без картинок: она покажется с меткой «Скоро», а после пересборки с картинками заменится сама.

## Ссылка на конкретную работу

`index.html#w=<id>`, например `#w=volta` или `#w=Pomodoro_Pantera_Ninja`. Язык: `?lang=en`.
